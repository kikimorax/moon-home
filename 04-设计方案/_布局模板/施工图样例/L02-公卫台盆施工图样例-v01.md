# 公卫台盆施工图表达样例 v01

日期：2026-10-05。图号：EX-01。用途：帮助用户认识施工图的组成与读图方式；这是表达样例，未签发施工，不改变当前布局或决策。

[查看SVG](L02-公卫台盆施工图样例-v01.svg)

四个视图采用不同示意比例，以尺寸标注为准，不可从画面量取安装尺寸。

## 四个视图

| 编号 | 图纸内容 | 能读出什么 |
|---|---|---|
| 01 | 台盆局部平面定位 | 台盆长宽、可用边界、保留端墙和名义安装余量；沿台盆长边旋转展开，未重画公卫全部墙体 |
| 02 | B向立面 | 台面高度、柜体底部和镜柜位置，以完成地面为高度基准 |
| 03 | 给排水与电气点位展开 | 给水W-01/W-02、排水D-01、电气EL-01如何用编号、横向尺寸和高度定位 |
| 04 | A—A柜体剖面示意 | 台面厚度、柜体高度、盆体与柜内空间、检修及连接说明如何表达 |

A—A在平面中表示剖切位置，B表示看立面的方向。本例剖面只说明表达方法，不是厂家构造详图；正式施工深化还要确定产品、材料、五金、支承及防水收口。

## 项目数据与演示假设

黑色尺寸沿用[公卫v06](../../L02-自主优化方案/平面图/L02-公卫设计-v06.md)（[SVG](../../L02-自主优化方案/平面图/L02-公卫设计-v06.svg)）：总段975包含120横墙，名义可用855；台盆长850、深550为当前候选，总余5。图中将5集中于左端方便读图，不确定最终安装缝分配。两卫原隔墙保留，右端墙厚画作符号，未给出实测厚度；本图不表示增加、恢复或拆除其他墙体。

以下蓝色带“＊”的数值**仅为演示假设，不是用户确认尺寸，不是产品要求，也不是通用施工标准**：

| 演示项目 | 假设值mm |
|---|---:|
| 台面完成高度 | 850 |
| 台面厚度 | 20 |
| 柜底离地 | 150 |
| 柜身高度 | 680，满足150＋680＋20＝850 |
| 镜底 / 镜顶高度 | 1100 / 1800 |
| 给水接口高度 | 550 |
| 排水接口高度 | 450 |
| W-01 / W-02距柜体左边的横向距离 | 350 / 500，假设中心间隔150 |
| D-01横向位置 | 柜体中线425，仅示意；实物位置待定 |

给排水坐标均为样例占位，现状接口、管径、排水形式和接法未确定；图中墙排符号只用于演示，未为项目选择墙排。EL-01只显示镜灯出线符号，其位置、标高、回路和防护要求全部待深化，不能据图放线或预埋。柜体外形、镜柜、盆体轮廓、分格及检修空间均为示意，不新增产品或柜内方案决策。

尺寸单位mm；±0.000表示完成地面基准。图上未给出线缆规格、保护器件、负荷、防水材料厚度及连接承托件，不能据此开展电气、拆改或柜体安装施工。

## 与正式施工图的关系

施工深化的成果通常包括施工图和配套材料、设备及做法表。正式图纸需要把本例中示意、待定项按完成面复尺和产品安装文件落实，补齐工程所需的总平面定位、管线路由和系统关系、节点索引及校审信息，并与实际现场交底一致。本样例未完成这些工作，仅用于认识表达方式。
