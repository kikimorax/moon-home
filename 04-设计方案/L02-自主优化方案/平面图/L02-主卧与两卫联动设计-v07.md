# L02 主卧与两卫联动设计 v07

日期：2026-09-29。状态：按用户确认的550毫米退墙计划绘制的候选平面，未冻结。

图纸：[联动v07 SVG](L02-主卧与两卫联动设计-v07.svg)。直接基于[联动v06说明](L02-主卧与两卫联动设计-v06.md)及[原SVG](L02-主卧与两卫联动设计-v06.svg)，原版保留。本版主卫BA02与主卧BR01之间增加次净衣凹位。

## 550毫米凹位与墙体折线

- 在v06右侧淋浴区下端，将原主卫下墙的右段向图上退550毫米，形成主卧侧开口的凹位；马桶后方的左段下墙保持原位。550为对应同侧墙面的名义退让量，不是柜内净深。
- 新增凹位左侧短墙，干区侧沿v06原淋浴玻璃的干区侧边界；墙体向凹位一侧占用，以避免向马桶侧扩出。新横墙与短墙连接成折线，凹位下侧不再封墙，地面与主卧相连。
- 右侧原黑墙、外窗及外墙轮廓保留；凹位在既有房间范围内形成，不在承重墙上削薄、开槽或嵌柜。
- 凹位完全内凹，收纳不越过v06原主卧墙面。图中以虚线标原墙面基准，标注“净宽／净深待核”，不直接把原淋浴900毫米拟宽写成凹位净宽。
- 墙体条带沿用源图的图形表达，不代表已选定墙厚。实际墙体、防水、饰面、柜体背板等确定后，再复核净宽、净深及收口。柜门、挂杆、搁板和内部尺寸本版不细化。

## 淋浴区与入口

- 主体纵深按 **1880−550＝1330毫米**标注，宽度沿用原约900毫米拟值；两者均非现场实测或完成面保证值。
- 右上错台轮廓按v06保留，不用像素补算其上伸尺寸。1330是主体段长度，不是包括错台的最长总长度。
- 原下段淋浴入口被凹位占用，故移除原固定玻璃及下段门口的表达，沿缩短后的左侧边界重新布置三联动移门候选，门片向图上收拢。
- 图中三片门线为闭合及叠合方向示意，不提供产品分扇、门片厚度或轨道尺寸。**净开口700毫米仅为目标**，须由实际产品核算门框、重叠、把手和有效开启范围，未据本图证明能够达到。
- 干区侧进出箭头落在台盆与马桶之间的共用空间。该箭头表示使用方向，不是700毫米通道，也不代表多人可同时无干扰使用。

## 平面校核与保留的限制

| 项目 | 本版校核结论 |
|---|---|
| 退墙量 | 新旧下墙对应同侧面名义位移550毫米；仅改变右侧淋浴下端，左段马桶后墙不动 |
| 剩余淋浴主体 | 1880−550＝1330；不以右上未知错台长度补足或宣称整区实测尺寸 |
| 马桶及台盆 | 外廓、朝向和位置沿用v06：台盆1000×500、马桶430×700均为拟值；新增短墙与两者在图面无直接相交 |
| 马桶右侧短墙 | 新短墙干区侧沿原玻璃边界，沿用约250毫米侧隙比较值；墙厚向凹位侧占用。实际抹灰、饰面、踢脚及突出五金仍须扣除，不宣称完成面净距已落实 |
| 马桶前方 | 原1880−500−700＝680毫米的局部紧凑关系继续存在；本次凹位没有改善这一限制 |
| 主卫入口门 | 原700毫米候选门扇、门弧与约150毫米开门侧余量保留；图面未碰到新增墙体，但不等于开门、转身与如厕互不影响 |
| 淋浴进出 | 门口已重排，进出仍与马桶前方、台盆使用空间共用；马桶旁250毫米侧隙不得当成通往淋浴的正常通道。净开口目标700也不等于干区接近空间宽700 |
| 主卧取衣站位 | 在原主卧墙面外画600×600毫米比较框，仅为拟动作空间；与源图床、床头柜、衣柜及入口门弧未直接相交，但与主卧通行空间共用，实际体型、柜门与站位仍需复核 |
| 主卧床柜 | 保留v06床、床头柜及约3300×600衣柜；原床尾约960、开500柜门后约460及窗帘收口等限制不变 |
| 凹位净尺寸 | 未取得实际墙厚、完成层或柜体构造，保留待核，不从SVG墙体条带宽度反推 |

**本版完成550毫米凹位的空间关系试排；淋浴有效开口、共用进出空间及实际凹位净尺寸尚未解决到施工层面。** 保留台盆、马桶的本轮范围约束，不通过缩小洁具、扩大外墙或改动承重边界隐藏冲突。
