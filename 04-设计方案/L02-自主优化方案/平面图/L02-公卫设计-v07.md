# L02 公卫设计 v07

日期：2026-10-06。空间：BA01。状态：候选试排，未冻结。

图纸：[本版SVG](L02-公卫设计-v07.svg)。单位为毫米，上南下北；下文上下左右均按当前实际图面。

## 布局与本轮依据

按用户本轮指令交换门与台盆、马桶与淋浴的位置：右上为外置台盆，右下为入口，左上为淋浴，左下为马桶。用户进一步确认横墙保留，但位置应随台盆和门的占宽调整；因此保留横墙厚120，将其定位作为本次拟值。门按用户手绘设右下门轴，向内朝下方的两卫隔墙打开。

两卫之间因排污管固定的原隔墙不动，黑墙、左侧墙窗及主卫514×317包管保留。台盆沿走廊一侧使用；仅在本版表达右侧台盆开口、门位及横墙的候选调整，具体墙端、拆砌范围、管线和收口仍须现场核验。

参考[卫生间装修避坑指南](../../../.agents/skills/weishengjian-zhuangxiu-bikeng/SKILL.md)中的外置洗漱区与改排水核验思路：保持洗漱在门外，使洗漱与如厕可以分开使用；将门向下方墙打开，避开上部台盆和淋浴入口。马桶与淋浴的位置互换只证明本次试排关系，不代表排水已经可改。

## 尺寸链与定位

公卫现状原墙范围1770×1864，来自用户量房及确认。以左上内墙交点为原点，x向右、y向下；下表是候选占地坐标，不是现场放线坐标。

| 对象 | 本次定位与尺寸 | 状态 |
|---|---|---|
| 上部台盆区 | 右侧纵向y0—900 | 900为试排分配，未复尺的完成面净长 |
| 台盆 | x1220—1770，y25—875；沿墙850、进深550 | 规格拟值；在900区段内上下各余25，总余50 |
| 内盆 | 410×620示意 | 未选产品，龙头、台面边距及排水待定 |
| 横墙 | x1220—1770，y900—1020；厚120 | 厚120为用户确认；y900定位为拟值，横向长度仅按台盆带示意 |
| 右侧门位 | y1020—1820；预留800 | 拟洞口占位，不是已选门扇宽或有效净宽 |
| 下端余段 | y1820—1864，名义余44 | 尺寸链残余，不是已测墙垛长度；门框及墙端收口待核 |
| 淋浴 | x0—1200，y0—900；1200×900 | 候选占地，未扣分隔构造与完成层 |
| 马桶 | x20—720，y1192—1572；纵向宽380，向室内长700 | 宽380沿用用户提供；长700、背后20为本次试排假设，未选型号、未核坑位 |

右侧纵向分配：**900＋120＋800＋44＝1864**。台盆850在900区段内名义余50；完成层、误差、封边和安装缝须包含在最终复尺与产品要求中，不能直接按本图下单。

横墙允许调整位置是本轮新指令；900台盆区和800门位是本次提出的尺寸分配，不将其记录为用户实测。门弧按800名义预留范围示意，实际门扇、铰链、门框和把手的占位另核。

## 平面校核与待处理项

| 校核项 | 结果与边界 |
|---|---|
| 门向 | 右下门轴，向内朝下方两卫隔墙打开；门轴与下方内墙之间仍有44名义余段，并非门扇已保证贴墙 |
| 门与马桶 | 800名义扫掠范围与700×380马桶试排占地不相交；开门和如厕共用前方空间，不据此保证同时使用或实际产品无碰撞 |
| 马桶上侧 | 1192−900＝292；900是淋浴候选边界，上侧还须扣半墙／分隔占位和完成层，不能当保证净距 |
| 马桶下侧 | 1864−1572＝292；按原墙边界计算，仍须按完成面复核 |
| 淋浴与台盆之间 | 1770−1200−550＝20；仅算术余量，分隔厚度、连接件、防水和饰面尚未落实，图中保留红色提示 |
| 淋浴入口 | 半墙名义长550，剩余1200−550＝650；未扣框、玻璃、重叠和五金，不是净开口 |
| 半墙 | 在上部淋浴的下缘左段示意；长度550为拟值，高度、厚度和具体构造未选定，图中线宽不代表墙厚 |
| 外置洗漱 | 台盆朝右侧走廊使用；虚线仅示意站位，走廊实际净宽、相邻门开启及柜体检修需联合核验 |
| 排水与防水 | 马桶坑位、排污连接、淋浴地漏、坡向及门口防水均未落实；不预选移位器、墙排或抬高地面的做法 |

本版可用于比较上下互换后的布局。20毫米分隔余量与44毫米门端收口仍是需要处理的紧张处；不得通过削薄黑墙、移动两卫固定隔墙或包管来消化它们。
