# Moon Home 装修设计项目

用于整理房屋资料、讨论布局与装修风格、迭代效果图，并逐步形成定稿。当前处于概要设计阶段，尚未选定风格或布局方案。

| 目录 | 内容 |

## 工作方式

1. 补充资料与居住需求，区分已确认事实、图示信息和推测。
2. 以用户标注原图 v02 的方向为讨论基准，建立统一底图；布局依次编号 L01、L02。
3. 获准保存时，在04中从 `_布局模板` 建立L目录，再在对应L内从 `_风格模板` 建立S目录；S注明采用的父布局修订版本，布局只维护一份。
4. 效果图使用如 `L01-S01-LD01-阳台视角-v01.png` 的名称，并附同名 Markdown 记录生成依据；布局修订后标记相关效果图待同步。
5. 比较方案；仅在用户明确要求保存时，按指定范围记录阶段摘要、关键决策或变更。最终版本经用户确认并明确要求保存后放入最终定稿。

讨论不逐条转录，也不要求补录全部历史会话。02维护当前有效输入，03保留当时的讨论依据；历史结论变化时注明后续替代关系，不改写成最新口径。保存讨论摘要不自动授权同步其他文档。

当前模板只用于组织文件，不代表已选择任何装修风格。后续先读取已有设计基础，再按阶段处理[待确认事项](02-设计基础/待确认事项.md)，不重复询问已提供的信息。
